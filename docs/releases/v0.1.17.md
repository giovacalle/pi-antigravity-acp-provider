# v0.1.17 — Restore automatic runtime updates

Tested with Pi 1.4.0 and Node.js >=22.19.0. ACP SDK 1.8.0 / stable protocol 1, wildcard host peers and permission defaults are unchanged.

## Fixes and updates

- Unblock the daily signed-runtime publisher by resolving all five dependency-audit findings. Update transitive body-parser to 2.4.0, fast-uri to 3.1.9 and qs to 6.17.0; override the development Pi dependency's vulnerable Undici pin with patched 8.12.2. Required audits remain enabled, including development dependencies (#57).
- Update both Pi development packages together to 1.4.0 and TypeBox to 1.4.3 (#56, incorporated into #57).
- Include the signed Antigravity ACP 1.4.3 catalog for all six supported platform/architecture combinations (#62). Close four duplicate runtime PRs after confirming identical release entries.
- Retain ACP SDK 1.8.0: the automated SDK 2.x bump removes APIs used by the provider and fails typechecking. Close #58 and document the requirements for a separate, coordinated migration rather than shipping an incompatible major update.

The Undici override patches this repository's development dependency tree, not a user's separately installed Pi host. Keep host dependencies updated independently.

## Validation

- Clean installation, typechecking and **292 ordinary tests** pass; eight opt-in official-runtime/live tests remain skipped. No authenticated inference or new OAuth flow was exercised for this release.
- Both supported Node CI lines check tests, package contents, isolated packed installation and the full dependency audit. Local Node 24 / npm 12 validation also passes.
- Full dependency audit reports **zero vulnerabilities** at release validation time.
- The normal runtime updater succeeds after the catalog merge. An end-to-end bot publication check also creates a whitespace-only signed-catalog PR, dispatches real CI on its exact head, and merges through normal branch protection (#63). No checks or protection rules were bypassed.

Synthetic tests and signature verification do not establish inference entitlement or cross-platform runtime qualification. The provider is not a sandbox.
