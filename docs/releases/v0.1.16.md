# v0.1.16 — ACP 1.4 model selection and safe recovery

Tested with Pi 1.3.0 and Node.js >=22.19.0. Stable ACP protocol 1 / SDK 1.8.0 remain unchanged. Pi host dependencies remain wildcard peers; the paired development packages are now pinned to 1.3.0.

## Fixes

- Support Antigravity ACP 1.4.x split model and thought-level selectors. Discovery exposes effort-qualified IDs for Pi's reasoning controls; selection sends the base ID and effort separately and confirms both (#48, #50, integrated in #52; fixes #49).
- Recognize category-less `thinking_level` / `thought_level` aliases consistently. Match the live selector inventory, including additional levels such as `off`, while preserving exact native model IDs.
- Reach the older `session/set_model` fallback when a selector silently ignores a value. Preserve real authentication, timeout, abort and transport errors and their causes instead of replacing them with a generic selection failure.
- Reject disappearing or ignored effort selectors and model drift during effort updates. Discard warm and saved bindings after failed model changes so a partially changed base cannot silently service the next request under a stale model ID.
- Derive discovery from live selectors rather than stale, base-only or duplicate legacy metadata. Retain legacy labels only when the full, duplicate-free inventory matches.
- Add explicit Argon fallback entries while retaining Gemini 3.8 Flash as the conservative offline/default choice. This does not grant Argon access to ineligible accounts.

## Runtime and dependencies

- Include signed Antigravity ACP runtime approvals through 1.4.1 (#44, #45).
- Update the paired Pi development dependencies to 1.3.0 and compatible dependencies, including security updates to Hono and transitive `ip-address` (#46, #47, #51, #52).
- Correct the documented Pi development/test version; Node.js requirements, default `yolo` permissions and automatic runtime-update behavior are unchanged.

## Validation and limits

- Typechecking and **292 ordinary tests** pass, including 14 added unit cases and 18 real-child-process integration cases. Eight opt-in official-runtime/live tests remain skipped during ordinary CI.
- Seven key new integration regressions fail on the unchanged #48 head and pass with the coordinated fixes.
- All three official-runtime contract tests pass against Antigravity ACP 1.4.1, including selection of every advertised model/effort and restoration of the original selection. No inference prompt was sent.
- Both supported Node CI lines validate typechecking, tests, package contents, isolated packed installation and the full dependency audit. Release validation also exercises npm 12 packaging.
- Full dependency audit reports zero vulnerabilities at release validation time.
- Synthetic tests and metadata-only checks do not establish inference entitlement, new-account OAuth success, or cross-platform macOS/Windows qualification. The provider is not a sandbox.
